## 已知边界（不写代码的教训，分镜设计时遵守）

- PuLID 会把画面里**所有的脸**换成参考脸 → 锁脸帧只能有一张脸（他人背对/低头/入阴影）
- 图生视频只能做"首帧里可见的"动作 → 一镜一个简单动作，起点必须在画面里
- SDXL 对"现代小物件+古代场景"组合理解弱 → 道具要具体化描写 + 抽卡
- 凡出现士兵/路人/配角，必须写朝代+服饰，否则写实底模默认画成现代人
- LoRA 只锁脸不锁死服装 → 每镜必须逐字写服装短语（不写就漂移成古装）
- LoRA 训练图必须无水印（沈砚 v1 用了带"豆包AI生成"水印的图，水印被学进模型）；攒图先检查右下角
- 多人对手戏构图 → 直接走可灵，别用 PuLID 硬刚
- 【战争/军队镜头三规则】①远景大阵不用视频模型：SD出静态图→zoompan运镜即可，人脸太小不锁脸 ②马匹/人群镜头动词一律"缓慢"（禁用"万马奔腾/激烈混战"），3秒一段再拼接 ③烟尘、硝烟、镜头晃动一律后期特效，不让AI生成（闪烁重灾区）；不训军队/战马LoRA（弱项会固化进模型）
- 【多主体 IP 参考的真相】Wan2.2 I2V 无原生多主体 IP 参考，ComfyUI 也无现成 Wan-IPAdapter——多人锁脸的正解仍是"每镜一个主体，他人入阴影/边缘"；seed 只稳画风不稳脸，锁脸只有 LoRA 一条路
- 【撞名警示】抖音已有百集付费剧《持械入宋》（112万赞，第九/十季在播）→ 本剧改名**《械启汴京》**，后续集数启用新名

- 收工必做：AutoDL 控制台【关机】（不然烧 GPU 费）
