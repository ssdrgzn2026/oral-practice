# AI 短剧产线边界清单（v1.0）

> 适用范围：Wan2.2 + ComfyUI（Kijai WanVideoWrapper）本地产线 / RTX 4090
> 用途：分镜评审、外包对接、新成员上手的第一份"别踩坑"文档
> 原则：清单只写**已经验证过的边界**和**明确不可行的方案**，未验证的一律进"待探索"，不进产线。

---

## 0. 先决事项：剧名撞名风险（优先级最高）

| 项 | 情况 | 处置 |
|---|---|---|
| 现状 | 已有在播百集付费短剧使用同名，热度高（百万级点赞），搜索位已被占据 | 立项前必须改名 |
| 风险 | ① 搜索流量被永久压制 ② 商标/著作权争议、平台投诉下架风险 ③ 用户混淆，付费转化受损 | 名称确定后同步做商标与平台检索 |
| 备选名 | 《械启汴京》《携器入宋》（另可自拟 2–3 个） | 定名后全流程统一替换，含文件命名、字幕、封面 |

**结论：定名前不开机。** 本条为立项阻塞项。

---

## 1. 技术边界：三条不可让步的铁律

1. **一镜一主体。** 单个镜头只锁一个角色；其他人走阴影、背影、侧脸、画面边缘、景别外。多人同框"各锁各脸"目前不落地，不投入。
2. **动作一律写"缓慢"。** 提示词只用"缓步推进 / 小跑 / 轻微扬起"，禁用"万马奔腾、激烈混战、奔腾冲刺"等强动态词。
3. **烟尘、硝烟、镜头晃动、动态模糊全部后期。** 不交给 AI 生成——AI 粒子与烟尘是闪烁重灾区。

---

## 2. 工具分工（谁管什么，不越界）

| 控制项 | 真正管什么 | 不管什么 | 我们的用法 |
|---|---|---|---|
| Seed（种子） | 画面随机基底、光影与画风基调、动态细节的随机度 | **不锁人脸，不保证连续镜头脸不变** | 同场次统一固定一个数值；作为可复现的基线，不作为锁脸手段 |
| I2V 首帧图 | 构图、人物站位、场景、起始画面 | 动起来后脸会漂 | 每镜的构图基准，必须先用 SD 出静态底图 |
| IP-Adapter / 多参考 | — | **Wan2.2 原生无多主体 IP 参考；ComfyUI 无稳定可用的 Wan 多人 IP 节点** | 现阶段不追多人锁脸；单人特写用 FantasyTalking 实现近似效果 |
| LoRA | 角色特征、服饰、画风 | 管不住大动作 | 单镜 ≤ 2 个：画风 LoRA + （必要时）主角 LoRA |
| 抽卡历史选用 | **实际上的锁脸手段** —— 从历史合格样本里挑 | — | 每角色建立合格样本库，新镜头优先复用已通过的那批参数组合 |

**一句话对照：** Seed 稳底子 / 首帧锁构图 / LoRA 锁特征 / 抽卡历史锁脸 / IP 参考（多人）**当前不可行**。

## 3. 镜头分类工艺表（分镜评审按此表核对）

| 镜头类型 | 制作工艺 | 消耗 | 硬性规则 |
|---|---|---|---|
| 多人文戏（议事厅、对话） | SD 静帧 → Wan I2V，固定 Seed，只锁主角一人 | GPU 分钟 | 配角压边缘/阴影；提示词写明"中心主角、左侧武将、右侧胖须将领"约束站位 |
| 远景军阵 / 航拍大阵 | SD 静态图 → 合成器 zoompan 运镜，**不跑 Wan** → 后期加沙尘 | ≈ 0 | 远景不锁脸（人脸太小，锁了也白锁）；阵型靠底图保证 |
| 近景骑兵冲锋 / 骑马 | 首帧图 + Wan，**单人**主体，"小跑/缓推"，3 秒一段拼接 | GPU 分钟 | 一镜一骑手；禁止多马同框 |
| 弩阵特写 | 静态底图 + Wan 只做手指扣扳机、弩箭微动 | 低 | 大幅度动作全部后期 |
| 高光打斗（仅点睛镜头） | 单人单镜生成 N 段 → 剪映分层抠像合成 → 后期叠加粒子烟尘 | 人工 | 全片用量控制在 5% 以内，不批量走 |

**禁止做法（写成分镜退回理由）：**
- ❌ 文生视频从零生成大军
- ❌ 单段 > 81 帧（3.3s）跑强动态
- ❌ 一堆马/人挤在同框让模型自己解决穿模

---

## 4. LoRA 纪律

- 不训练：骑兵 LoRA、战马 LoRA、军阵 LoRA、群演 LoRA。原因：会把这些弱点（畸形马腿、抖动人群）固化进模型。
- 常驻只用 2 个名额：
  - 全局画风 LoRA：0.4
  - 主角角色 LoRA：0.45（仅当镜头里有主角）
- 群演、小兵：放弃锁脸，靠画风统一。远景观众看不出差别。

---

## 5. 参数标准（全片统一，不许个体发挥）

| 参数 | 标准值 |
|---|---|
| 帧数 | 81 帧（≈3.3s）以内，长镜头分段生成再拼 |
| 帧率 | 24 fps |
| 采样步数 | 24 |
| CFG | 5 |
| 分辨率 | 同场次内完全一致，不得中途改 |
| 采样器 | 同场次内完全一致 |
| Seed | 同场次共用一个固定值 |

> 先低分辨率预览试跑，确认脸型、阵型、构图没问题再出高清。禁止直接高清抽卡。

## 6. 提示词模板

### 6.1 远景军阵（航拍 / 平原大阵）
**正向：** 航拍俯拍，宋代平原军阵，整齐步兵方阵，红旗，骑兵向前缓慢推进，地面扬起淡淡的沙尘，黄昏柔和侧光，长阴影，镜头缓慢向前推，画面稳定，阵列不扭曲，马匹整齐，电影质感，与参考图构图一致
**负向：** 阵型混乱，马匹肢体崩坏，马腿畸形，人物扭曲，剧烈抖动，闪烁，变形，多出旗帜，破碎

### 6.2 近景冲锋（单人）
**正向：** 单人骑兵，战马小跑，挥剑幅度小，尘土缓缓扬起，缓推镜头，与首帧构图一致
**负向：** 高速冲撞，剧烈翻滚，马腿畸形，四肢穿模，多人同框，闪烁

### 6.3 多人议事（三人同框）
**正向：** 中心男主居中正坐，左侧武将，右侧胖须将领，构图与首帧一致，人物基本静止，仅有轻微呼吸与衣袖摆动，柔和侧光
**负向：** 人脸变化，五官漂移，角色换脸，人物位置移动，剧烈动作，变形

## 7. 后期清单（这些永远不进 AI）

- [ ] 烟尘 / 硝烟 / 火星 → 粒子特效（AE 或剪映）
- [ ] 镜头晃动、手持感 → 后期位移
- [ ] 动态模糊 → 后期
- [ ] 多骑手叠加 → 分层抠像合成
- [ ] 统一调色 → 全片一批完成，保证跨镜头一致

---

## 8. 一致性保障：跨镜头不割裂

1. 同场景 → 同 Seed、同提示词、同 LoRA 权重、同分辨率、同采样器。
2. 镜头衔接 → 把上一镜**最后一帧**作为下一镜的 I2V 首帧，实现无缝过渡。
3. 每镜 ≤ 3 秒，长段落用多段拼接，不要指望一次生成十几秒。
4. 每角色维护 3 张正面高清参考图，全剧复用。

## 9. 待探索能力（不进产线，另行排期）

当前 WanVideoSampler 上已有两个输入口，节点已装好，只需下载配套模型：

| 能力 | 价值 | 优先级 | 状态 |
|---|---|---|---|
| **MultiTalk**（multitalk_embeds）| 本地音频驱动对口型，特写台词镜头可替代可灵，省积分 | **P1** | 待测，赶在可灵试用包到期前做效果对比 |
| **FantasyTalking**（fantasytalking_embeds）| 单人脸参考驱动表情，近似"IP 锁脸"的 Wan 版实现 | P2 | 待测，仅限单人特写 |

**边界提醒：** 这两个都解决不了多人同框锁脸，只解决单人特写。不要外推。

## 10. 生产 SOP（顺序不可乱）

1. **定名** → 完成撞名与商标检索，全流程统一。
2. **SD 批量出静帧**：远景军阵、近景单人骑手、弩阵特写、文戏底图，统一黄昏侧光与色调。
3. **逐张做 Wan I2V**：同段落固定同一 Seed；每镜一主体；动作写"缓慢"。
4. **筛选**：删掉畸形、闪烁、穿模片段，合格样本进"抽卡历史库"。
5. **剪映合成**：分层叠加骑手 → 粒子烟尘 → 动态模糊 → 统一调色。
6. **质检**：按第 1、3 节逐条核对。
7. **字幕配音** → 导出。

## 6. 抽卡纪律（首帧图验收，触发即弃用重抽）

Wan 只会把首帧动起来，永远不会修复首帧的错。以下三种卡**看到就弃，不将就别做 Wan**：

1. **乱入元素**：动物、现代军装/装备、汽车、现代建筑、首帧里没有的道具
2. **服装/发型错**：林策出现古装/束发/武器/箭囊；沈砚出现非青袍
3. **场景不对**：要求汴京街市却出拱廊/宫殿/荒野/隧道

---

## 7. 出片验收三问（每镜合成前必答）

1. **说话人在画面里吗？** 台词/字幕的说话人必须是本镜主体；双人同框时"谁有台词谁是主体"
2. **关键道具在吗？** 剧情题眼道具（手电/光柱/折扇）必须出现在首帧里——动态提示词只写已有元素怎么动
3. **脸和上一镜一致吗？** 同角色跨镜对比，一眼不像就重抽/重锁，不指望观众看不出来

> 表演幅度规范：motion prompt 表情词一律 subtle/slightly 前缀（subtle flinch, eyes widen slightly），
> 禁写 flinches back sharply / wide open mouth——避免表情包式夸张，守住写实基调。
